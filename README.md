# Система управления заявками на закупки

Веб-приложение для создания, согласования и контроля заявок на закупки 
с разграничением прав по ролям.

---

## Технологии

| Слой | Технология |
|---|---|
| Язык | Java 21 |
| Backend-фреймворк | Spring Boot 3 |
| Доступ к данным | Spring Data JPA (Hibernate) |
| Авторизация/аутентификация | Spring Security |
| UI | Vaadin Flow |
| База данных | PostgreSQL |
| Миграции схемы БД | Liquibase |
| Сборка проекта | Maven |
| Хеширование паролей | BCrypt |

---

## Роли и права

| Роль | Права                                                                                                                                                                                              |
|---|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **EMPLOYEE** | Может создавать заявки, редактировать и удалять их в статусе `NEW`. После смены статуса заявка становится доступна только для просмотра и изменения, но не для удаления. Видит только свои заявки. |
| **MANAGER** | Может создавать заявки и видит все заявки. Способен менять статус любой заявки, но не редактировать содержимое и удалять ее.                                                                       |
| **ADMIN** | Полный доступ: редактирование содержимого, смена статуса, удаление, ручное переназначение утверждающего.                                                                                           |

Статусы заявки: `NEW`, `PENDING_APPROVAL`, `APPROVED`, `REJECTED`, `COMPLETED`.

---

### Настройка подключения

Проверьте `src/main/resources/application.properties` - по умолчанию приложение
ожидает базу `purchase_requests_db` на `localhost:5432` с пользователем
`postgres`/`postgres`. При необходимости поправьте под своё окружение.
